# Cargo Guard

Сервер и страница учебного стенда. База MongoDB на этом компьютере. Позже адрес базы и папка фото меняются переменными `MONGO_URL` и `PHOTO_DIR`, код правил остаётся.

Полное описание ветки и запуск для напарника: [docs/изменения.md](../docs/изменения.md). Рабочая ветка `backend/mongo`.

## Запуск

Служба MongoDB уже должна быть запущена.

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Страница и API открываются вместе: http://127.0.0.1:8000/

Проверки правил:

```powershell
cd backend
$env:MONGO_DB='cargoguard_test'
.\.venv\Scripts\python -m pytest -q
```

## Роли стенда

Пароль совпадает с логином.

| Логин | Роль | Кто на экране |
| --- | --- | --- |
| controller | Контролер | Мамбетов Р. Р. |
| accounting | Бухгалтерия | Соколова Е. М. |
| admin | Администратор | Черакаев А. А. |
| security | Служба безопасности | чтение журнала |

Группу по массе назначает сервер. Группа 0–3 кг не уходит в пункт выдачи без файла кадра. Повторное закрытие не пишет вторую строку. Комиссию считает сервер.
